# QQ 称呼映射

用 QQ 号固定群友称呼，群聊里持续按称呼表叫人；同一个 QQ 再次设置新称呼时自动覆盖旧称呼。

## 为什么需要

AstrBot 默认能知道发送者昵称，但昵称会变、也不一定是你想叫的称呼。这个插件把“QQ 号 → 固定称呼”持久化：

- 你告诉机器人“QQ 123456 是张哥，哥哥”
- 之后群里就用“张哥”称呼
- 再告诉她“以后叫张哥2”，旧称呼自动被覆盖

## 功能

- QQ 号 → 称呼（可带关系备注）持久保存
- 同一 QQ 新称呼覆盖旧称呼
- 每次 LLM 请求自动注入称呼表
- 额外注入“当前发送者 QQ + 称呼”，群聊里不容易叫错
- 支持命令和自然语言
- 仅主人可设置
- 纯本地 JSON，不调用 LLM，零 token 额外开销（除称呼表本身）

## 安装

1. 把插件目录放到 AstrBot 的 `data/plugins/astrbot_plugin_dafeiyu_alias/`
2. 重载/重启 AstrBot
3. 在插件配置里填写 `owner_ids`（允许设置称呼的 QQ）

## 命令

| 命令 | 权限 | 作用 |
|---|---|---|
| `/称呼 QQ号 称呼 [关系]` | 主人 | 设置/覆盖单个称呼 |
| `/称呼批量 QQ=称呼/关系;QQ=称呼/关系` | 主人 | 一次设置多条 |
| `/称呼列表` | 主人 | 查看称呼表 |
| `/称呼删除 QQ号` | 主人 | 删除称呼 |

示例：

```text
/称呼 123456 张哥 哥哥
/称呼批量 123456=张哥/哥哥;654321=李四/群友
/称呼列表
/称呼删除 123456
```

## 自然语言

主人可以直接说：

> 记住这两个 QQ：111222 是王姐，姐姐；333444 是赵哥，哥哥。以后按这个称呼。

模型会调用批量工具 `set_aliases`，参数形如：

```text
111222=王姐/姐姐;333444=赵哥/哥哥
```

一次给多个 QQ 时必须走 `set_aliases`，不要塞进单次 `set_alias`，否则可能触发工具参数 JSON 解析失败。

## 配置

| 配置 | 类型 | 说明 |
|---|---|---|
| `enabled` | bool | 是否启用 |
| `owner_ids` | string | 允许设置称呼的 QQ，逗号分隔 |
| `max_prompt_aliases` | int | 注入提示词的最大称呼数量，默认 30 |

## 存储

映射保存在：

`data/plugin_data/astrbot_plugin_dafeiyu_alias/aliases.json`

纯本地文件，可直接备份、迁移或手工编辑。

## 权限

只按 `owner_ids` 判断，与消息平台无关；非主人无法使用设置/查看/删除命令，也无法调用 `set_alias` / `set_aliases`。

## 兼容性

- AstrBot `>= 4.5.0`
- OneBot v11 / aiocqhttp
- 不依赖第三方 Python 包
